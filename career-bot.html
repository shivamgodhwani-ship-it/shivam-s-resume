Career Bot

Internship Application Automation Pipeline  ·  Solo Build  ·  2026

Scrape  →  Score  →  Tailor  →  Submit, end to end

The Problem

Applying to internships at scale is mechanical work disguised as decision-making: find listings, judge fit, adjust the resume, submit, track. Most of that loop doesn't need a human in it — except the judgement calls that determine whether the system is actually pointing at the right roles.

What I Built

01
Listing Scraper

Automated scraping of internship listings using Playwright, built to handle dynamic, JavaScript-rendered job boards rather than static pages.

02
LLM Relevance Scoring

Each listing is scored for relevance against a candidate profile using the OpenRouter API — filtering volume down to roles actually worth applying to.

03
Auto-Tailored Resume Bullets

Resume bullets are automatically adjusted per role based on the listing's language and requirements, rather than submitting one static resume everywhere.

04
Automated Submission

The pipeline completes the loop by submitting the tailored application directly, closing the gap between scoring and action.

05
Flask Tracking Dashboard

A dashboard for end-to-end application tracking, audit logging, and pipeline monitoring — so the automation stays auditable, not a black box.

Engineering Details

Application state is persisted in SQLite, giving the pipeline a durable record of what's been scraped, scored, tailored, and submitted. API keys are managed through environment variables rather than hardcoded — a basic but easily skipped security practice in personal automation projects.

Outcome

Multi-Module Pipeline

Scraping, scoring, tailoring, and submission as distinct, auditable stages

Full Tracking Dashboard

End-to-end visibility into every application the system touches

Secured Configuration

Environment-variable based API key management

Stack

Built with Python · Flask · Playwright · SQLite · OpenRouter API

Key Takeaway

Automation is only useful if you can still see inside it. The dashboard and audit logging mattered as much as the scraping and scoring — a pipeline applying on your behalf needs to stay legible, not just fast.
